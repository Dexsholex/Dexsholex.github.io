Confidencialidade e proteção de dados

Inventários de plantações, limites de explorações, plantas de locais e imagens de levantamentos são muitas vezes comercialmente sensíveis. É assim que os trato.

Antes de o trabalho começar

  • Assino de bom grado um acordo de confidencialidade antes de partilhar o que quer que seja. O seu ou o meu, como preferir.
  • O âmbito escrito diz que dados vou receber, o que vou produzir e a quem pertencem os resultados.

Durante o projeto

  • Os seus dados são usados apenas no seu projeto. Não servem para treinar modelos para mais ninguém e não são partilhados.
  • O acesso está limitado às pessoas que trabalham no seu projeto, e quem nele trabalhar fica sujeito às mesmas condições de confidencialidade.
  • Os dados de localização são removidos das fotografias antes de qualquer uma ser mostrada fora do projeto.

No fim

  • Recebe os resultados, o código e a documentação.
  • Devolvo ou apago os seus dados, como preferir, e confirmo-o por escrito.

Dados pessoais

Alguns projetos envolvem dados pessoais, como nomes de produtores associados a parcelas ou localizações de agregados familiares. Trato-os de acordo com a Lei nigeriana de Proteção de Dados de 2023 (Nigeria Data Protection Act) e, quando se aplica, com o Regulamento Geral sobre a Proteção de Dados da UE (RGPD): apenas os dados pessoais de que o projeto precisa, usados apenas para o fim acordado e guardados só durante o tempo necessário.
