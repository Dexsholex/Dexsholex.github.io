Privacidade

Este site não recolhe nada sobre si. Os pormenores estão abaixo, incluindo o que acontece se me enviar um e-mail.

Neste site

  • Sem cookies, sem estatísticas, sem scripts de rastreamento, sem publicidade e sem formulários que enviem dados.
  • Se mudar entre o modo claro e o escuro, ou escolher um idioma, essa escolha fica guardada no seu próprio navegador para que o site a lembre. Nunca é enviada para lado nenhum.
  • O site não procura saber onde está. Se o seu navegador estiver configurado noutro idioma disponível no site, pode sugerir essa versão, e quem escolhe é você.
  • O mapa interativo só carrega ficheiros deste site. Não são pedidos mosaicos de mapas nem tipos de letra a terceiros.
  • A ferramenta de pedido da página inicial escreve um e-mail no seu próprio programa de correio. Nada é enviado até ser você a enviá-lo.

Alojamento

O site está alojado no GitHub Pages. Para operar e proteger o serviço, o GitHub pode registar dados técnicos como o seu endereço IP. Consulte a declaração de privacidade do GitHub (em inglês).
