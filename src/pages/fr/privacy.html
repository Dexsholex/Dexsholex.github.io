Vie privée

Ce site ne collecte rien sur vous. Les détails sont ci-dessous, y compris ce qui se passe si vous m'écrivez.

Sur ce site

  • Aucun cookie, aucune mesure d'audience, aucun script de pistage, aucune publicité et aucun formulaire qui envoie des données.
  • Si vous passez du thème clair au thème sombre, ou si vous choisissez une langue, ce choix est enregistré dans votre propre navigateur pour que le site s'en souvienne. Il n'est jamais envoyé nulle part.
  • Le site ne cherche pas à savoir où vous êtes. Si votre navigateur est réglé sur une autre langue proposée par le site, il peut vous suggérer cette version, et c'est vous qui choisissez.
  • La carte interactive ne charge que des fichiers de ce site. Aucun fond de carte ni aucune police externe n'est demandé.
  • L'outil de demande de la page d'accueil rédige un e-mail dans votre propre messagerie. Rien n'est envoyé tant que vous ne l'envoyez pas vous-même.

Hébergement

Le site est hébergé sur GitHub Pages. Pour faire fonctionner et sécuriser le service, GitHub peut enregistrer des informations techniques comme votre adresse IP. Voir la déclaration de confidentialité de GitHub (en anglais).
