Conteo de palmas aceiteras con imágenes aéreas

Para una plantación comercial: un proceso de detección de copas con YOLOv8 que cartografió {{ palm.palms }} palmas en {{ palm.hectares }} ha y {{ palm.blocks }} bloques. Las entregas solapadas se conciliaron para que cada hectárea se contara una vez, lo que eliminó {{ palm.double_counts }} conteos duplicados.

Susceptibilidad a inundaciones GeoAID, Amuwo-Odofin (Lagos)

Un modelo abierto con panel en línea: susceptibilidad estructural a inundaciones, lluvia casi en tiempo real y exposición de personas, escuelas, centros de salud y carreteras. ROC-AUC de alrededor de 0,798 con división aleatoria y de alrededor de 0,642 con validación cruzada espacial, presentados juntos.

Lagos Access Map (en desarrollo)

Una auditoría, barrio por barrio, de hasta qué punto OpenStreetMap recoge los centros de salud de Lagos, con intervalos de confianza, como base para cartografiar el acceso a la atención sanitaria.
