Privacy

This site doesn't collect anything about you. The details are below, including what happens if you email me.

On this site

  • No cookies, no analytics, no tracking scripts, no advertising and no forms.
  • If you switch between light and dark mode, that choice is saved in your own browser so the site remembers it. It is never sent anywhere.
  • The interactive map loads only files from this site. No third-party map tiles or fonts are requested.

Hosting

The site is hosted on GitHub Pages. To run and secure the service, GitHub may record technical details such as your IP address. See GitHub's privacy statement.
